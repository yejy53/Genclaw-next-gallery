正文的第一段承担导语的作用，通常交代结论：这套版式把正文限制在 760px、图与表放宽到 1040px、脚注区再放宽到 1280px，靠三档栏宽而不是靠字号变化来制造节奏。

段落之间的间距是 16px，章节之间是 80px。所以连续的叙述读起来是连贯的，而每遇到一个二级标题，视觉上都会有一次明确的停顿。

## 二级标题起一个新章节

二级标题 28px，字重 450——不是加粗。整篇文章几乎不出现粗体，强调靠的是留白、栏宽和顺序，而不是字重对比。这也是这类研究报告读起来"安静"的原因。

行内元素都可用：**强调**只把字重提到 450，`行内代码`用等宽字体，[站内链接](/zh)与[外部链接](https://example.com)会自动区分（外链带 `target="_blank"`）。

### 三级标题用于章节内的细分

三级标题 22px，与上文的间距收紧到 48px，让它明显归属于前一个二级章节，而不是另起一节。

- 无序列表用自绘的 6px 圆点，替换掉浏览器默认 marker
- 每项之间 10px，保持紧凑
- 列表项的字号与正文一致，不额外缩小

1. 有序列表保留数字
2. 用于步骤、排名或需要引用编号的场合
3. 编号与文字之间的距离固定

> 引用块用左侧 4px 蓝条加浅填充，右侧收圆角。适合放结论、引文或一句需要被单独看见的话。

## 图、表与代码

只包含一张图片的段落会自动变成 `figure`，宽度放到 1040px；图片的 markdown title 会渲染成图注。

![占位图](/blog/placeholder-wide.svg "图 1：图注 14px，字重 330，居中显示在图片下方")

表格同样使用宽栏，并带横向滚动容器，窄屏不会撑破布局。

| 元素 | 字号 / 行高 | 字重 | 栏宽 |
| --- | --- | --- | --- |
| 一级标题 | 32 / 38 | 450 | 1040 |
| 二级标题 | 28 / 36 | 450 | 760 |
| 三级标题 | 22 / 28 | 450 | 760 |
| 正文 | 17 / 28 | 330 | 760 |
| 图注 | 14 / 23 | 330 | 1040 |

代码块保持正文栏宽，用等宽字体与浅色底：

```python
def render(markdown: str) -> str:
    """正文里的代码块不做语法高亮，只保证节奏与可读性。"""
    return to_html(markdown)
```

## 可用性说明

右侧中间那条竖线是目录。它平时只显示一条 2px 的滚动进度轨，鼠标移上去才展开成完整的章节列表，并给整页盖一层模糊遮罩。窄屏下自动隐藏。

## 脚注 {#footnotes}

脚注区之后的所有内容都会切换到 1280px 宽，字体换成衬线体——这是原版留给大表格和参考文献的处理方式。

1. **一号脚注。** 脚注正文用衬线体，用于放数据来源、评测设置这类需要与正文区分开的说明。
2. **二号脚注。** 这一区的宽度足够放下一张完整的对比表格。
